# 논문 요약

출처: 박지원·양치복, 「RAG 프레임워크에서 검색과 생성 성능의 관계 분석」 제공 수정 원고. 이하 페이지는 PDF 페이지 번호입니다. 외부 출판 정보나 참고문헌의 사실관계를 별도로 검증한 문서는 아닙니다.

## 연구 질문

검색 지표가 좋아지면 RAG의 최종 답변 품질도 좋아지는가? 이 연구는 임베딩 모델과 풀링 방식을 바꾸면서 검색·생성 단계의 성능 우위가 일관되게 유지되는지, 질문 유형과 검색 문서 수가 그 관계를 어떻게 바꾸는지 분석합니다(pp. 1–6).

## 연구 방법

BioASQ4의 질문 중 summary 유형을 제외한 1,022개 질문을 사용합니다. 질문에 연결된 PMID로 PubMed 문헌을 수집하고, 중복·빈 값을 처리해 13,007개 문헌을 구축합니다. 원고에는 수집 전후 문헌 수가 13,072개와 13,007개로 보고되어 있습니다(p. 9).

문헌을 500자 청크, 100자 중첩으로 분할한 다음 네 임베딩 모델에 CLS·Mean·Max 풀링을 적용합니다. 동일한 방식으로 질의를 임베딩하고 ChromaDB에서 Top-k 청크를 검색합니다. k는 5, 10, 20입니다. 검색된 청크와 질문을 Gemma 3 4B에 입력해 답변을 생성합니다(pp. 5–10).

| 모델 | 모델 식별자 |
|---|---|
| S-BERT | `sentence-transformers/all-MiniLM-L6-v2` |
| BGE | `BAAI/bge-m3` |
| Solon | `OrdalieTech/Solon-embeddings-large-0.1` |
| Gemma 임베딩 | `google/embeddinggemma-300m` |

검색은 Recall@k와 nDCG@k, 생성은 factoid의 MRR, list의 F1, yesno의 Macro-F1로 평가합니다. 생성용 Gemma와 임베딩용 Gemma는 서로 다른 모델입니다.

## 주요 결과

### 질문 유형별 성능 전달

원고의 Mean–CLS 비교에서는 list가 검색과 생성 간 가장 일관된 경향을 보입니다. factoid는 검색 단계에서의 풀링 차이가 생성 단계에서 완화되며, yesno는 일부 모델에서 검색과 생성의 우세한 풀링이 반대로 나타납니다(p. 12). 이는 관찰된 조건부 경향이며, 통계적 인과관계가 입증되었다는 뜻은 아닙니다.

### 최고 설정의 불일치

표 4에서 factoid는 검색과 생성 모두 BGE가 우세하지만 풀링이 CLS에서 Mean으로 달라집니다. list는 Solon–Mean이 우세하지만 최적 k가 20에서 10으로 바뀝니다. yesno는 검색의 Solon–Mean–20에서 생성의 S-BERT–CLS–5로 모델·풀링·k가 모두 바뀝니다(p. 13). 세부 수치는 [README](../README.md)에 정리했습니다.

### Top-k 증가의 효과

표 5에서 검색 성능 변화량은 대체로 양수지만, 생성에서는 일부 음수가 보고됩니다. 예를 들어 yesno의 BGE–CLS는 −0.0214, S-BERT–Mean은 −0.0226입니다. 검색 문맥 증가가 생성 성능 향상으로 반드시 이어지지 않는다는 관찰을 뒷받침합니다. 이 변화량을 모든 설정에 적용되는 보편적 효과로 해석해서는 안 됩니다(p. 14).

### 풀링 선택

원고는 Mean의 전반적인 안정성과 일부 모델·유형에서 CLS의 경쟁력을 보고합니다. Gemma 임베딩은 CLS보다 Mean에서 나은 결과를 보입니다. 특정 풀링 하나가 모든 모델과 질문에 최선이라는 결론은 제시하지 않습니다(pp. 10–12).

## 기여와 적용 시사점

검색 지표만으로 RAG 구성을 결정하기보다 최종 생성 답변까지 함께 평가해야 한다는 실증적 근거를 제공합니다. 질문 유형에 따라 검색 문서 수와 임베딩·풀링 전략을 달리 검토할 필요가 있으며, 임베딩 차원이나 모델 크기만으로 답변 품질을 예상하기 어렵다는 점을 보여줍니다(pp. 15–16).

## 한계

- BioASQ 생의학 데이터에서 관찰한 결과이므로 다른 도메인으로의 일반화는 확인되지 않았습니다.
- 생성 모델은 `gemma3:4b` 한 종류이며 다른 LLM과의 비교는 수행되지 않았습니다.
- k=5/10/20과 고정된 청크·프롬프트 조건을 사용했습니다. 재정렬, 문맥 필터링 등은 후속 연구 대상입니다.
- 원고 표 4의 검색 점수 정의와 본문 수치 불일치, 데이터 버전 및 평가 구현 확인 사항이 남아 있습니다. [재현 안내](reproducibility.md)에 기록했습니다.

## 한 문장 정리

이 실험에서 검색과 생성의 최적 조건은 질문 유형에 따라 달랐으며, 높은 검색 성능이 높은 답변 품질을 항상 보장하지는 않았습니다.
